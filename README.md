# BallisticsCore

The current plugin is **Networked Projectile System (NPS)**, located in [`NPS/`](NPS/).

NPS provides deterministic projectile, hitscan, and explosive simulation for Unreal Engine, with server-authoritative, client-predicted, and client-authoritative networking.

## Install

Copy `NPS/` into your Unreal project's `Plugins/` directory, regenerate project files, and build the project's Editor target. The development target is Unreal Engine 5.8 on Win64.
